# Source verification

Confirm the user intends the specific external operation before enabling it; otherwise remain local/offline. Send only the minimum citation data required. Separate returned source evidence from formatting findings. CourtListener retrieval is not Shepard's or KeyCite and does not establish treatment, good-law status, controlling weight, or proposition support. Preserve unresolved results and label external provenance.
