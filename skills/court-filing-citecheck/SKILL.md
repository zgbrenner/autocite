# Court-filing citecheck

Call AutoCite with Bluepages mode or confirm a conflicting detection. Preserve all prose and filing structure. Inspect every short-form resolution and show unresolved candidates. Apply only returned `safe_auto_fix` edits; request approval for all other changes. Treat local rules, good-law status, weight, treatment, and proposition support as separate source/human review. Never substitute memory for AutoCite output.
