- Complete unit/integration suite, Ruff, compileall, gold and safety evaluations.
- Deterministic/retrieval critical safety gates and socket-blocked offline path.
- Wheel/sdist build, packaged local reference data, dependency lock, SBOM generator, and checksum workflows.

## Open release items

- Real local-Qwen, reranker, GLiNER, CPU/GPU hardware matrix and corrupted-model journeys need optional-runtime CI hardware.
- Windows/macOS signing, notarization, native installer/uninstaller, no-admin installation, accessibility audit, repair installation, and complete cache-removal UX need platform release infrastructure.
- Advanced desktop outline/footnote/graph/per-change workflows remain incomplete.
- Dependency and model license counsel review is required before commercial redistribution.

AutoCite 0.5.0 is therefore suitable as an alpha local deterministic/MCP release with optional experimental ML, not a fully hardened or fully Bluebook-compliant product.
