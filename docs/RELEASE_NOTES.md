# Release Notes — 0.5.0

AutoCite 0.5.0 adds structure-preserving document parsing, a document-wide citation graph, declared contextual rule families, local licensed Markdown retrieval, a serious evaluation framework, hardened local MCP packaging, an initial PySide desktop shell, and reusable host-routing skills.

Critical safety gates pass with zero unsupported facts, unsafe automatic edits, non-citation prose changes, unresolved-antecedent guesses, or local-mode network calls in the held-out deterministic test run.

This is an alpha with partial tested rule coverage, not complete Bluebook compliance. Real Qwen/reranker/GLiNER/GPU ablations, platform signing/notarization, advanced desktop inspectors, native installers, and broader licensed evaluation remain open.
