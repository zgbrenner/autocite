# Trust and Safety Model

The original document is immutable input. AutoCite never invents source facts and abstains on ambiguous antecedents. Every result labels deterministic logic, parsed structure, retrieval, model inference, external verification, or unresolved ambiguity. Only high-confidence mechanical changes are automatic.

Local/offline is default: no telemetry, document logging, public bind, or review-time download. External case verification requires explicit enablement. Formatting never proves validity, treatment, weight, good-law status, or proposition support.

Known boundaries are published in the coverage matrix and evaluation report. Unsupported means unsupported, not silently valid.
