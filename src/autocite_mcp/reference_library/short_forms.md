# Id. antecedents

Use an Id. form only when the immediately preceding authority is unambiguous. Multiple authorities, intervening citation material, or incompatible pinpoint information should produce review rather than a guessed antecedent.

# Case short forms

A shortened case name should trace to a prior full case citation using exact identifying components. A later full citation can support consistency review but cannot retroactively validate an earlier short form.

# Supra and supra note

Supra forms require a permissible prior source. Cases and statutes use their own short-form systems. A referenced note containing several possible sources is ambiguous unless the text itself uniquely identifies one.
